# WM6.5 桌面 · 使用说明（6.5 现行版）

本说明按 **`WM6.5桌面.apk`（`com.wm65.launcher`，versionCode 56 / versionName 6.5）** 与配套 **`便笺.apk`（`com.msn.localnotes`，versionCode 12 / versionName 2.0）** 的实际行为重写。界面、配色、图标、贴纸样式保持原版，功能改动只集中在「便签双向联动」和它引发的刷新、剪辑问题。

---

## 一、装什么、先装哪个

| 文件 | 包名 | 版本 | 作用 |
|---|---|---|---|
| `WM6.5桌面.apk` | `com.wm65.launcher` | 6.5 / 56 | 桌面本体（WM6.5 钛金风格启动器 + 标签记事本卡片） |
| `便笺.apk` | `com.msn.localnotes` | 2.0 / 12 | 纯本地便签 App，桌面卡片的数据来源 |

**安装顺序：先装便笺，再装桌面，最后把 WM65 Launcher 设为默认桌面。**

三个必须先知道的事：

1. **两个包都是重签版**，和原版 WM65 Launcher / 微软便笺的签名不同。设备上已装过原版的，必须**先卸载再装**，否则系统会报「签名不一致 / 应用未安装」。
2. **卸载旧桌面会清掉桌面布局、壁纸绑定和旧便签缓存；卸载便笺会删掉全部便签数据**（内容存在应用私有目录）。升级前请先在便笺里把要留的内容复制出来。
3. **便笺不能卸**。桌面上的「标签记事本」卡片没有自己的数据，全部通过 `content://com.msn.localnotes.notes` 从便笺读取；便笺被卸载、被冻结或被降级到 2.0 以下，卡片立刻空掉。

## 二、桌面基本操作（原版逻辑，未改）

**Today 页（第一页）**
- 大时钟：点按打开绑定的时钟应用，长按可更换应用 / 恢复默认。
- 中文日期行（如「2026年11月9日 星期一」）：点按跳系统日历。
- 天气：点按打开绑定的天气应用，长按可更换 / 手动刷新 / 恢复默认；平时约 30 分钟自动更新。
- 音乐行：有播放时居中显示「♪ 歌名 - 歌手」，点开来源音乐 App，没播放时自动隐藏（需授予通知使用权）。
- 双击空白 → 锁屏（需先开无障碍权限，仅 Today 页有效）；长按空白 → 换壁纸。

**手势与面板**

| 手势 | 效果 |
|---|---|
| 上下滑 | 翻页（Today → 插件页） |
| 左滑 | 拉出记事本面板 |
| 右滑 / 点 Win 徽标 | 拉出应用抽屉（「开始」） |
| 面板内反向滑 | 收起当前面板 |

**四角快捷键**：左上设置、右上微博、左下电话、右下微信；长按任一角键可「更换应用 / 修改名称 / 恢复默认」。

## 三、标签记事本卡片（桌面 ↔ 便笺双向联动）

卡片在 Today 页，走的是桌面自带那张「标签记事本」，只是数据从「自己存」改成了「读便笺」。

- **顶部标签栏**：「全部」+ 便笺里建过的每个分类。点某个标签，只看该分类的便签。
- **点一条便签** → 直接打开便笺的**全屏编辑页**（不是小弹窗），可改正文、改分类、分享、删除。
- **点「新建」** → 打开便笺的**全屏新建页**，并把当前选中的分类预填进去（格式 `[分类] `）。
- **自动刷新**：从便笺改完回到桌面，卡片会立刻读一次，并在 0.9 秒、2.5 秒各补读一次 —— 因为便笺是在**退出编辑页那一刻**才落盘，回桌面瞬间数据可能还没写完。
- **不会再莫名空态**：如果卡片记着一个历史筛选标签而便签里没有该分类，会自动回落成「显示全部」；每次读取也会把残留的筛选条件清掉。
- **新建的便签**：保存后回到桌面，最迟 2.5 秒内出现在卡片上。

## 四、便笺 App 操作（v2.0 分类版）

- **列表页**：顶部是分类筛选栏（「全部」「未分类」+ 每个分类）。卡片上显示分类小标签、正文摘要和时间。右下角 `+` 新建。
- **编辑页**：
  - 左上「删除」，右上「完成」，右上另有「分享」。
  - 顶部中间「分类：xx」，点开是分类选择对话框，可选已有分类或当场新建。
  - 「分享」走系统分享面板，发出的是纯文本：`[分类] 正文`。
- **存储格式**：正文写成 `[分类] 内容`；没选分类记为「未分类」。便笺按修改时间倒序排列。
- **保存时机**：退出编辑页（`onPause`）时落盘。所以「点完成 → 直接回桌面」的情况下，卡片首读可能还是旧数据，等 2.5 秒补读即可。
- **纯本地**：数据就是 `filesDir/notes/<id>.txt`，不联网、不需要账号、不写云端；卸载即删，没有恢复途径。
- **悬浮便签已移除**：v11 起删掉了「贴到桌面」按钮、`OverlayService` 和悬浮窗权限 —— 之前在桌面图标上压一张便签、观感差、宽度还拉不动，已废弃。

## 五、6.5 这一版具体改了什么

| 改动 | 说明 |
|---|---|
| 便签读通道 | 桌面 `NoteStore` 全量改走便笺 Provider（`all/add/update/remove`），标签前缀 `[分类]` 由便笺侧拆分到 `g` 字段 |
| 全屏编辑 / 全屏新建 | 点便签、点新建都跳便笺的编辑页；跳转失败时兜底退回桌面，不会点了没反应 |
| 分享 | 编辑页新增「分享」，一键把整条便签发到微信/邮件/任意支持文本的 App |
| 诗词单行完整 | 强制单行；按控件真实排版宽度（`Layout.getLineWidth`）按比例缩字号，整句完整显示，不折行、不截字 |
| 时钟不再整块消失 | 首页渲染前加了页面容器空值守卫，冷启动应用列表还没扫完时也不会中断首页渲染；自动重建后会补刷时钟 |
| 图标列表刷新 | `LauncherApps.Callback` 即时监听装/卸 + 回桌面重扫 + 抽屉显式刷新，图标秒级更新 |
| 版本号 | `versionName` 直接定为 **6.5**，`versionCode` 递增到 56（覆盖安装要求递增） |

## 六、图标刷新的最终方案（装/卸即时生效）

这台机器（以及不少国产 ROM）**不会把系统卸载/安装广播可靠地投递到第三方桌面**：`PACKAGE_REMOVED`、`PACKAGE_ADDED` 的静态注册、动态注册全都试过，均无效果，图标只能等到桌面 60 秒应用缓存过期才变化。

排查到最后发现，真正的原因不在「刷新触发」，而在**刷新漏了一个清单**：桌面里应用图标由两份互相独立的缓存驱动 ——

1. 主面板（环状快捷图标）：每个格子记录 `panel_0…panel_N` 槽位，按包名去缓存里查实体；
2. **应用抽屉（「开始」菜单）：`DrawerPanel` 内部保存一份自己的应用列表快照，只有调用它自己的 `refreshApps()` 才会更新。**

之前各版都只做了「清缓存 → 重扫 → 重绘主面板」，从未刷新过 `DrawerPanel`，所以抽屉里始终是旧快照：卸载的图标一直在、新装的根本不出现。

最终做法（versionCode 52 起，v56 保持）：

- 注册 `LauncherApps.Callback`（`registerCallback`），这是系统专门给桌面启动器的包变更回调，不受隐式广播限制，装/卸完成时直接触发；
- 触发后：清应用缓存 → **同步**重新扫描 → 重绘主面板 **+ 显式调用 `DrawerPanel.refreshApps()` 刷新抽屉 + 刷新角标**；
- 另加一条廉价兜底：回到桌面后 0.6s～70s 间多次比对「包名集合指纹」（数量 + FNV 哈希），一变就立刻重扫重绘，不重载图标，无卡顿。

配套注意事项：
- 不要用「清缓存后立刻重绘但不重扫」的写法 —— 会整屏停在「正在加载…」。
- 主屏格子指向的应用被卸载后，该格子会空出来，点一下可重新指定（原版设计如此）。

## 七、已知限制（别当 BUG 反复折腾）

1. **微软账号同步不可用**：便笺是重签包，微软 OAuth 注册绑的是原包名 + 原签名指纹，登录必失败（`AADSTS50011` / `invalid_client`）。本套方案只用本地便笺，不要试图登录微软账户。
2. **第三方 AppWidget 在桌面小组件列表里看不到**：原版就不支持，非本次改动。
3. **桌面「标签记事本」只认本便笺**：它不会读微软 To Do、小米便签等其它应用。
4. **数据随卸载消失**：两个 App 都没有导出功能，重要内容先复制出去。
5. **回桌面有轻微扫描延迟**：见第六节，属于当前方案的代价。

## 八、常见问题对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 卡片一直显示「还没有便签」 | 便笺没装、被降级到 2.0 以下，或被系统冻结 | 装/升级到便笺 2.0，手动打开一次 |
| 卡片有内容但点不开 | 便笺被冻结或后台被限制 | 允许便笺自启动/后台运行 |
| 新建的便签桌面没有 | 便笺在退出编辑页才落盘 | 等 2.5 秒，或再进出桌面一次 |
| 卸载 App 后图标还在 | 旧版只刷新了主面板，没刷新应用抽屉 | 用 versionCode 56（已修） |
| 整屏「正在加载…」卡住 | 清缓存后没等重新扫描就重绘 | 用 6.5 版，已改成先扫后绘 |
| 时钟整块消失 | 冷启动时应用列表未就绪导致首页渲染中断 | 用 6.5 版（含守卫与补刷） |
| 诗词少字 / 折行 / 被「…」截断 | 旧版固定 10 字，或字号自适应只在部分页面生效 | 用 6.5 版（versionCode 56：单行 + 按真实排版宽度缩字号） |
| 安装报「签名不一致」 | 设备上有原版或旧签名的包 | 先卸载，再装本目录里的重签包 |

## 九、本目录里的东西

`out/` 是构建现场，保留完整可追溯：

| 路径 | 内容 |
|---|---|
| `WM6.5桌面.apk` | 桌面成品（6.5 / 56，已签名） |
| `便签.apk` | 便笺成品（2.0 / 12，已签名） |
| `classes.jar`、`classes/`、`dex/`、`gen/` | 桌面补丁类（`NoteBridge`、`NoteSyncReceiver`、`QuoteFit`）的编译中间产物 |
| `base.apk`、`unsigned.apk`、`aligned.apk`、`aligned-v2.apk`、`WM65Launcher.apk.idsig` | 便笺构建过程文件与签名结果 |
| `res.zip` | 便笺资源打包中间产物 |
| `pack_dex.py` | 把 `classes.dex` 以根路径追加进 APK 的脚本（不能用 `zip -r`，否则 `resources.arsc` 被压缩，Android 11+ 装不上） |
| `sources.txt` | javac 源文件清单 |
| `wm65.keystore` | 桌面/便笺共用的重签证书（alias `wm65`） |

**注意**：`wm65.keystore` 是签名私钥。如果这个仓库是公开的，任何人都能用它签出「看起来同源」的更新包 —— 需要的话可以把它从仓库里删掉，或改用私有仓库保存。

# WM65 Launcher v3.1 使用说明

Windows Mobile 6.5 钛金风格的 Android 启动器。纯 Java 零依赖，minSdk 28 / targetSdk 35，原生流畅运行于 Android 15 及以上（含更新的原生系统）。

## 安装
1. 安装 `WM65Launcher.apk`（覆盖安装保留设置）。
2. 按 Home 键选「WM65 Launcher」为默认桌面。

## 主屏幕布局
| 位置 | 默认 | 说明 |
|---|---|---|
| 左上角 | 设置 | 点按进入启动器设置 |
| 右上角 | 微博 | 点按打开微博 |
| 左下角 | 电话 | 点按打开拨号盘 |
| 右下角 | 微信 | 点按打开微信 |
| 底部中央 | Win 徽标 | 点按打开应用抽屉，**长按可更换自定义图像 / 恢复默认 / 进设置**（四角全改掉后仍能找到入口） |

**四角快捷键均可自定义**：长按任一角键 →「更换应用 / 修改名称 / 恢复默认」，名称与跳转应用都能改。

## Today 页（第一页）
- 时钟与天气为**全透明文字浮层**（无卡片底），文字带阴影保证任意壁纸上可读。
- **大时钟卡片短按** → 打开绑定的应用（默认系统时钟）；**长按时钟卡片** → 更换跳转应用 / 恢复默认。v2.4 起按日历同款逻辑：选定的应用**必定打开**（缓存未就绪时直接按包名兜底启动，绝不静默回落默认）。
- **中文日历行**（大时钟下方）：显示「2026年11月5日 星期四」（已去掉上午/下午），**点按即跳转系统日历**（优先跳到今天；无日历 Provider 时按常见日历包名兜底）。
- **天气卡片**：城市 + 当前温度 + **中文天气** + 5 日预报（每日含中文天气与高低温）。
  - **点按天气** → 打开绑定的应用（默认天气应用，长按可换成任意应用）。
  - **长按天气** → 更换跳转应用 / 手动刷新 / 恢复默认；平时每 30 分钟自动更新（联网获取，无后台常驻）。
- **音乐小部件**：正在播放时在天气卡下方**居中显示**「♪ 歌名 - 歌手」（无任何左侧标签文字），点击打开来源音乐 App；没有播放时自动隐藏。需在系统设置授予**通知使用权**（读取媒体会话用）。
- **双击空白** → 锁屏（需先开启无障碍权限，仅 Today 页有效）；**长按空白** → 更换壁纸。
- 小部件默认**屏幕正中**；长按任一小部件 →「移动小部件 / 缩放小部件 / 居中显示」。四个小部件（时钟、天气、消息、音乐）同属一组，移动时一起走。

## 手势（v1.9）
| 手势 | 效果 |
|---|---|
| 上下滑 | 翻页（Today → 插件页），200ms 落定 |
| **左滑** | 拉出**记事本面板**（自右侧跟手滑入，主页向左视差淡出） |
| **右滑** | 拉出**应用抽屉**（自左侧跟手滑入，主页向右视差淡出）；点 Win 徽标同样效果 |
| 面板内反向滑 | 收起当前面板（抽屉向左滑回 / 记事本向右滑回） |
| 双击空白 | 锁屏（仅 Today 页） |
| 长按空白 | 换壁纸（仅 Today 页） |

**v2.2 起抽屉与记事本是主屏幕内的面板 View**（不再是独立 Activity）：手指一动面板就跟着动，松手用 Material 标准曲线（fast-out slow-in，约 220ms）吸附，没有"松手后才开始动"的等待。面板顶栏有 ✕ /「‹ 桌面」可直接收起，返回键同样先收面板。

## 记事本独立页（左滑进入 · 右滑返回）
背景**完全透明**（壁纸直接透出）。
- 页头显示当前绑定的记事本应用（含图标）；默认优先检测**微软 To Do**（微软桌面自带便签），未安装回落小黄条。
- **＋ 新建便签**：一次填完内容 + 标签（标签可留空 → 未分类）。
- **标签胶囊行**：点按筛选；**长按标签** → 重命名 / 删除该标签（重命名自动迁移所有便签，删除则便签归入未分类）——标签栏自由更换。
- **点按任意便签 → 即时编辑**（弹窗预填内容与标签，参考微软便签「点一下就能改」的设计）；**长按便签** → 编辑 / 删除 / 打开记事本应用。
- **应用自由替换**：长按页面空白 →「更换记事本应用」；设置页「标签记事本」卡片仅保留**更换应用**一项（v2.4 已按需求移除小黄条下载等选项）。
- 未安装绑定应用时，页头显示「未安装 · 点按下载」，点击跳应用市场。
- 列表可滚动，显示**全部**便签；顶部「‹ 桌面」或返回键同样回桌面。

## 插件页（下滑翻页）
- 每页最多 **6 个**插件行（v2.3 起信息密度更高）。
- 每行**通栏全屏宽毛玻璃圆角卡片**（与屏幕同宽，半透明白渐变 + 高光描边 + 20dp 圆角），点击带脉冲动画反馈。
- **点击**插件 → 打开应用；**长按**插件 → 更换关联应用；插件数量在设置页调（1~99）。

## 应用抽屉
- **5 / 4 / 3 / 4 缓波序列**（短行居中缩进，相邻行只差 1 个图标，不会出现只剩 1 个图标的孤行），WM 风格圆形图标底，原生惯性滑动。
- **长按图标**弹出 Android 原生风格动作面板（32dp 大圆角卡片 + 圆角胶囊菜单项）：添加到主页插件 / 向前移 / 向后移 / 应用详情。
- **顶栏微软图标长按** → 更换自定义图像 / 恢复默认（与主屏底部中央图标独立设置）。
- **新安装的应用自动追加**到抽屉末尾（后台增量扫描）；卸载自动消失。
- 右上角 ✕ 或返回键关闭。

## 壁纸（v2.4 增强）
- 长按桌面空白 → 图库选图（本地缓存 + 设系统壁纸）。
- **第三方改壁纸同步**：除回桌面时轮询外，新增系统**壁纸变化推送监听**（OnColorsChangedListener），第三方壁纸应用设置成功后桌面立即跟进；读取兼容 `getDrawable(FLAG_SYSTEM)` 与无参 `getDrawable()` 两种 ROM 行为。

## 流畅性说明（v1.6~v1.9 关键修复）
- 应用列表**只读内存缓存**：包扫描只在后台线程执行，UI 线程永不扫描——彻底消除"没有响应"弹窗。

### v1.9 过渡动画提速
- 弃用系统默认 300ms 的 `fade_in/fade_out`，改为自定义 **130ms 淡入 / 110ms 淡出**。
- 横向切换统一为 **190ms 侧滑**（左滑进记事本、右滑进抽屉），带轻微视差与透明度过渡；返回时反向滑回。
- 翻页吸附动画 **320ms → 200ms**；底部动作面板滑入 **240ms → 180ms**，并新增 150ms 退出动画（原来是系统 300ms 淡出）。
- 按压反馈 70/160ms → **70/130ms**，点击脉冲 70/140ms → **55/120ms**，反馈更跟手。
- 左/右滑在 `PanelPager` 内部直接识别并**跟手位移**（阻尼 0.45），松手才判定，避免"先等一会儿再动"的迟滞感。

### v2.0 交互零延迟 + 稳定性
- **点击不再等 300ms**：原来用 `onSingleTapConfirmed`，它会硬等双击判定窗口（约 300ms）才派发，这是"点了半天才有反应"的主因。改用 `onSingleTapUp`，抬手即响应；双击锁屏改由 `onDoubleTap` 单独处理，并判断"上一次点击是否已触发动作"，避免点了时钟/天气后紧接着被误锁屏。
- **滚动期间开硬件层**：翻页拖动/吸附/左右滑视差期间给页面加 `LAYER_TYPE_HARDWARE`，带阴影的大字不再每帧重绘，静止后自动释放显存。
- **不做无谓重建**：回桌面时若面板数量、对齐方式、应用缓存状态都没变，直接跳过整树重建；重建时**保留当前页码**，不再跳回第一页。
- **稳定性加固**：所有跳转统一走 `Ui.safeStart`（目标不存在只提示、不崩溃）；应用扫描逐个 try/catch，单个应用异常不影响整体；四角选应用改用缓存查找，绝不在主线程做全量包扫描。

### v2.1 壁纸上窗口层（重影/透视/黑屏根治）
> v2.0 把窗口背景置空是错误方向：SurfaceFlinger 没有可清屏的内容会残留旧帧，
> 导致主页多套内容叠影、设置页透视出主页、应用切换黑屏。v2.1 改用原生 Launcher 的做法。
- **壁纸设为窗口背景**：`window.setBackgroundDrawable(壁纸)`，由系统窗口层直接绘制——
  窗口创建首帧就有图，**从应用返回桌面壁纸瞬时可见，无图片延迟**；切换动画期间窗口始终带壁纸，**不再有黑/无色过渡**。
- **根治页面重影**：窗口每帧以壁纸清屏，旧帧不再残留；内容透明处透出的是自己窗口的壁纸而不是后面的 Activity，**设置页透视问题同步消失**。
- **反而更省**：壁纸只画一次（窗口层），根视图不再铺整屏，比 v1.9 及更早版本少一层全屏绘制。
- **各页面零色差**：主页/抽屉/记事本/设置/应用选择器共用同一张壁纸窗口背景，页面互切无色彩断层。
- **去重不重复应用**：按"壁纸路径 + 内容版本"记录每个页面已应用的壁纸，相同直接跳过，onResume 不再触发整窗重绘；换壁纸后版本号自增，各页面自动更新。
- 每个窗口使用独立 Drawable 实例（`newDrawable`），避免多窗口共享状态串扰。

### v2.2 面板内嵌 + 跨应用零动画（延迟与重合的最终修复）
- **左右滑不再启动 Activity**：抽屉（`DrawerPanel`）与记事本（`NotesPanel`）改为主屏幕内的 View，
  手指位移 → 面板与主页同步视差 → 松手 Material 标准曲线吸附（220ms）。
  省掉一次 IPC + 新窗口创建，**起手即动，零延迟**；也不再有两个窗口动画叠加。
- **手势在派发层识别**（`dispatchTouchEvent`）：纵向意图立刻交还给翻页/列表滚动，互不打架；
  横向意图确认后向子视图补发一次 CANCEL 再接管，按压态不会残留。
- **跨应用切换零动画**：新增 `Ui.startExternal`——启动第三方应用时显式 `overridePendingTransition(0,0)`。
  之前给外部应用也施加了滑入/淡入动画（它作用于"即将显示的那个 Activity"，跨进程同样生效），
  对方窗口带着位移+半透明进场，与桌面动画叠加，就是**两个应用交替时的轻微重合**。
- **主页在面板打开时淡出并停止绘制**（alpha→0 + INVISIBLE），面板是半透明的，避免透出主页造成重影。
- **内存更省**：删除 `DrawerActivity` / `NotesActivity` 两个 Activity（Manifest 同步移除）；
  面板空闲时预构建（idle，不占首帧），关闭后 GONE（不绘制、不占合成层），复用不再重建。

## v3.3 变更摘要（修复「只能上下移动」）

1. **真正原因不是任何设置被锁定**（`widgetAlign` 只参与页面重建判断，已不参与布局）。是两套手势在抢事件：`dispatchTouchEvent` 里的全局横向手势（右滑开抽屉 / 左滑开记事本）在水平位移超过 2×touchSlop 时，会向子视图发 `ACTION_CANCEL` 并接管后续所有 MOVE，小部件的拖动监听从此收不到水平位移；垂直拖动不与横向手势冲突，所以只有 Y 生效。录屏量化也证实：0.5s 与 1.5s 两帧的时钟左/右边缘都固定在 16% / 66%，只有垂直位置变了。
2. **第二层原因**：消息 / 音乐小部件一出现，固定宽 0.78 屏宽的卡片把内容栈撑到接近整屏，`maxOffsetX = (舞台宽 − 内容宽)/2` 骤降到接近 0，同时被夹成负值的位移会被存下来 —— 这就是「刚装时居中、用一次之后只能靠左」。
3. 修复：移动模式下横向手势整体让位（提示语已注明，轻点即退出）；水平可移动范围设下限；消息 / 音乐卡片收窄到 0.62 / 0.46 屏宽；升级时一次性清掉旧的水平位移，保留缩放与垂直位置。
